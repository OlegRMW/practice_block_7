## Артефакты и усреднение

Каждый evaluate создаёт snapshot `results/<model>/runs/<run_id>/`. Старые запуски сохраняются; `scores_by_run.csv` содержит отдельные столбцы каждого критерия каждого судьи/запуска, также BLEU/ROUGE. Canonical source — snapshots и длинный `judge.csv`, широкий CSV — производное представление.

Для каждого судьи считаются средние полных успешных запусков по общим ID внутри одинаковых условий. Общая оценка — 50% GPT + 50% GLM, независимо от числа запусков каждого судьи. Разные лимиты/адаптеры/precision/prompts не смешиваются. Запуск без API не добавляет прежние значения в качестве нового независимого голоса. Ресурсы инференса в report — последний запуск группы, обучение — отдельные записи с run kind и adapter ID.
